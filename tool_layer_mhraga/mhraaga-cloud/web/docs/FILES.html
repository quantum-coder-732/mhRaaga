Generated by tools/gen_files_doc.py from each file's own header line, with hand-written lines where a file has none. Folders of generated data are summarised in one row.

Music engine (music_engine_framework_layer/mhraaga_engine/)

File Lines What it holds
__init__.py 9 mhRaaga music engine: raga grammar, the 72 melakartas, 16,000 gopi ragas, talas, score composer, LLM brief.
autotune.py 52 Auto-tune to the raga's shruti.
brief.py 212 Prompt to music brief. OpenRouter (GLM flash, DeepSeek flash fallback) plans the song as JSON; if the model is unreachable or returns junk, keyword rules produce the brief so the app still works offline.
compose.py 228 Score composer. A raga is a grammar, so the song follows the classical form
gan.py 76 Phrase GAN: a small generative adversarial network that invents melodic phrases for Kalkee's producer agents.
gan_weights.json 1 The trained phrase-GAN weights (generator and discriminator matrices). Loaded by gan.py.
lyrics_bank.py 94 Offline verse bank: couplets in seven languages, native script, grouped by theme. The agentic loop draws a mukhda and an antara from the same theme so every language has varied lyrics without an LLM call.
physics.py 230 Rigid-body physics for musical feel, on the real Box2D engine (pybox2d 2.3.10) when it is importable.
poems.py 42 Spoken-poem bank (poems_bank.json): short rhymed spiritual-love poems per language, used when a song is a poem.
poems_bank.json 517 The bank of short rhymed spiritual-love poems per language, used by poems.py.
ragas.py 194 Raga knowledge. Notes are semitones above Sa (0-11); 12 is the upper Sa, negatives are the lower octave.
styles.py 62 Style tags to musical choices, the way Suno's "Styles" box works: free words like "sufi qawwali, harmonium, dholak, handclaps, building crescendo".
tala.py 21 Talas: beat count, vibhag (sections) and a tabla bol per beat. Bol classes the browser synth knows: dha/dhin/dhi (both drums), na/ti/tin/ta (right drum), ge/ka/kat (left drum), 'x' = khali (open, softer).
agentic/__init__.py 2 Agentic layer: producer agents compose songs, critic agents score them, Kalkee's Shapley credit assignment splits each reward, and Thompson-sampling posteriors learn which choices make better music.
agentic/critics.py 168 Critic agents: each scores one aspect of a finished score in [0, 1]. Pure functions, stdlib only, deterministic.
agentic/evolve.py 249 The self-improving loop.
agentic/library.py 99 Reference tunes: analyse real recordings (ffmpeg to pure-Python Goertzel chroma + energy-envelope tempo) into compact profiles that the critics compare generated songs against. Profiles are cached in data/library_profiles.json.
agentic/make_poems.py 72 Offline poem factory: asks the language model for short rhymed spiritual-love poems (the style of the reference tunes: plain words, couplets, Radha-Krishna imagery) in each language and stores them in data/poems.json.
agentic/train_gan.py 49 Train the phrase GAN (numpy). Offline tooling: python -m mhraaga_engine.agentic.train_gan Data: 8-note phrases from the grammar (pakad, rise, fall) of every classical raga and a sample of melakartas and gopi ragas.
agentic/data/library_profiles.json 296 Pitch-class and tempo profiles of the reference tunes, used by the library_affinity critic. Only numbers, no audio.
agentic/data/poems.json 517 Candidate poems written offline by make_poems.py.
agentic/data/policy.json 902 The agents' learned beliefs: a Beta(alpha, beta) pair for every option of every agent, per language.
agentic/data/catalog/ ~100 files Up to 100 generated songs (one JSON each: score, brief, review, genes), plus index.json and report.json.

Backend API (tool_layer_mhraga/mhraaga-cloud/api/)

File Lines What it holds
admin.py 449 Admin dashboard API: users, roles, custom columns, usage and cloud cost. Every route needs an administrator.
handler.py 461 mhRaaga API: one Lambda behind API Gateway (HTTP API). Stdlib + boto3 only (boto3 ships with the Lambda runtime).
jobs.py 128 AI singer jobs: lyrics + style to a finished song with a real sung vocal, made by the open YuE2 model on a GPU machine.
local_server.py 94 Run mhRaaga locally with the exact Lambda handler: static site + /api, DynamoDB replaced by a JSON file.
studio.py 404 Studio routes: AI rules (ethics) in S3, People profiles with voice samples, Stories / Pravachan / Explainer scripts. Imported by handler.py; helpers are fetched lazily from it to avoid a circular import.
team.py 316 Shared studio: many artists work in one project (film or song) at once.
voice.py 192 Neural voice: text to speech as real audio the browser can mix with the music (Suno-style), not device speech.

Singer layer (tool_layer_mhraga/singer/)

File Lines What it holds
__init__.py 9 The singer layer: turns an mhRaaga song into a request for YuE2, an open model that SINGS the words.
abc.py 89 mhRaaga score to ABC notation for YuE2 (two voices, Vocal and Ins, 4/4, sixteenth-note grid), so the sung melody is the raga's own.
colab_singer.ipynb 97 Notebook that runs the singer on Google Colab's free GPU (two versions of the Qawwali song).
request.py 36 Build a YuE2 request from an mhRaaga song: style words, tagged lyrics, and the raga melody as the score.
examples/tu_hi_tu.requests.json 22 The two YuE2 requests (Devanagari and romanised lyrics) for the original Qawwali-style song.
