All the agents

"Agent" is used in three places in this project. They are different things, so they are listed separately.

1 · The live productServices that run when you press Create2 · The song factoryOffline agents and critics that improve the catalogue3 · KalkeeA separate orchestrator; mhRaaga borrows one function

1 · The live product

These run inside the Lambda or on your device when you create a song. They are ordinary code, not autonomous agents.

PartFileWhat it does
Brief plannerbrief.pyTurns your prompt into raga, tala, tempo, mood, language and lyrics using a language model; falls back to keyword rules.
Composercompose.pyWrites the alap, gat and tihai, the tabla bols and the lyric timing.
Physicsphysics.pyBox2D rubato, note weight, meend glide and drift. A pure-Python solver if Box2D cannot load.
Phrase GANgan.pyA small generative network that invents phrases; rule checks decide whether to use them.
Auto-tuneautotune.pyPulls pitch toward the shruti; snaps the last note to Sa.
Voicevoice.pyNeural speech for each lyric line, cached and shared; device voice as fallback; daily cost caps.
Translatorhandler.py /translateTranslates text between the supported languages.
Story and pravachan writerstudio.pyPlans a long spoken piece as an outline, then writes each section.
Film plannerstudio.pyTurns a story into scenes for the film studio.
Rules and learningstudio.pyLive rules in S3 and learned defaults per language, applied to each new song.
Team studioteam.pyShared projects of up to 150 members and 300 layers, with roles and optimistic locking.

2 · The song factory (offline)

Seven producer agents each choose one thing. They choose with Thompson sampling: each option has a Beta score per language, and the agent samples from it, so good options win more often and untried ones still get a turn. A composer renders the song, critics review it, and the reward is split fairly among the producers.

ProducerChooses fromJudged by
ragaclassical · gopi · melakartaraga_fidelity, library_affinity
talateental, keherwa, dadra, rupak, jhaptal, ektal, adicadence, rhythm
tempo54, 62, 70, 80, 92, 104 bpmrhythm, library_affinity

The critics

Eight rule-based critics (seven judge a song, and poem_form replaces rhythm for a poem). They are rules, not listeners.

CriticQuestion
raga_fidelityDo the notes belong to the raga? Are vadi and samvadi stressed?
cadenceDoes the final phrase land on sam?
phrase_varietyAre phrases varied, not copies?
contourDoes the melody rise and fall in a singable shape?
rhythmDoes the tabla keep the tala (songs only)?
lyrics_fitDoes the script match the language, and does the lyric pacing fit?
library_affinityHow close is the profile to the reference tunes?
poem_formFor poems: line shape and pauses (used instead of rhythm)

Fair credit

The reward is split with the Shapley value so an agent is credited for what it added, not just for being on a good song. This is the one function taken from Kalkee. If it is missing, a proportional split is used and the run records local-fallback.

The catalogue holds at most 100 songs (about 14 per language); a better song replaces the weakest. Details: Song factory agents.

3 · Kalkee

Kalkee is a separate multi-agent orchestrator in orchestrator_framework_layer_kalkee/. It routes each task to the best agent with a contextual Thompson-sampling router and runs a six-step pipeline (understand, plan, execute, validate, respond, evaluate). Its nine default agents are below. mhRaaga does not run any of them. The live site, the API and the app never import Kalkee. mhRaaga's song factory loads only the Shapley credit function.

Kalkee agentWhat it is
pm-agentWraps the original PM chatbot verbatim.
pm-agent-adkThe same chatbot, pinned to Google ADK.
openclaw-agentA plain Claude agent with no tools.
coding-agentWrites code and checks it parses.
mcp-utility-agentIts tools all come from MCP servers.
langchain-research-agentA LangChain pipeline with retrieval.
code-security-agentScans Python for vulnerability patterns.
supply-chain-agentLooks up dependency vulnerabilities (OSV.dev).
cloud-config-agentScans Dockerfile, Kubernetes and Terraform for misconfigurations.
